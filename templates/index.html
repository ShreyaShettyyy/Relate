About Relate (LuxStore)

Relate is an intelligent e-commerce platform that seamlessly merges online shopping with data-driven machine learning. It discovers real-world product relationships, mines transaction baskets, and delivers context-aware product and accessory recommendations in real time.

Project Objectives

Personalized Experiences

Deliver individualized product feeds based on customer transaction histories and category affinities rather than static trending lists.

Discover Product Relationships

Identify which items naturally complement each other using mathematical Market Basket Analysis (Apriori algorithm).

Analyze Purchasing Patterns

Evaluate multi-item transaction logs to calculate Support, Confidence, and Lift metrics for bundle detection.

Real-Time Model Updates

Dynamically append new customer checkouts to the transaction dataset and retrain association rules on-the-fly.

Machine Learning Algorithms & Mathematical Foundations

Algorithm 1

Apriori Algorithm (Market Basket Analysis)

The Apriori algorithm mines frequent itemsets across transaction logs by enforcing the Apriori Principle (anti-monotonicity): all non-empty subsets of a frequent itemset must also be frequent.

Anti-Monotone Property:
If itemset X is not frequent, no superset (X ∪ Y) can be frequent.

In Relate, transactions are converted into a binary one-hot matrix ($TransactionID \times Item$). Apriori generates candidate $k$-itemsets from ($k-1$)-itemsets and prunes any combination falling below the minimum support threshold ($\text{min\_support} = 0.001$).

Algorithm 2

Association Rule Mining (Support, Confidence, Lift)

From frequent itemsets, association rules in the form $A \rightarrow B$ are constructed, where $A$ is the antecedent (e.g. iPhone 13 Pro) and $B$ is the consequent (e.g. Screen Protector).

Support
$$\text{Support}(A \rightarrow B) = \frac{\text{Transactions containing } A \text{ and } B}{\text{Total Transactions } N}$$
Measures how frequently the combination occurs.
Confidence
$$\text{Confidence}(A \rightarrow B) = \frac{\text{Support}(A \cup B)}{\text{Support}(A)}$$
Probability that $B$ is bought given that $A$ was bought.
Lift
$$\text{Lift}(A \rightarrow B) = \frac{\text{Confidence}(A \rightarrow B)}{\text{Support}(B)}$$
Lift > 1: Positive dependency; items are complementary.
Algorithm 3

Personalized Hybrid Recommendation Architecture

Relate combines collaborative transaction rules with content-based TF-IDF attribute similarity and category-level compatibility constraints:

  • Accessory Compatibility Matrix: Guarantees that smartphones pair with chargers, cables, and cases; laptops pair with wireless mice, stands, and hubs; and cameras pair with memory cards, tripods, and lenses.
  • Content Similarity: Uses Scikit-learn TF-IDF Vectorizer and Cosine Similarity to find direct competing products within the same category.
  • Negative History Filtering: Excludes non-replenishable hardware already purchased by the customer while preserving complementary add-ons.
